Como usar
• O site abre em cada aparelho com a largura real dele, então o CSS de celular é aplicado igual ao do aparelho.
• Toque, teclado virtual e o navegador do celular não são simulados: a conferência final continua sendo no celular de verdade.
• Se um aparelho ficar em branco, o site bloqueia ser aberto dentro de outra página. Use ↗ para abrir em nova aba.
• Para ter os diagnósticos automáticos (rolagem lateral, botões pequenos, letras pequenas, links de WhatsApp), abra esta ferramenta pelo servidor da pasta da agência. Veja o LEIAME.md.
