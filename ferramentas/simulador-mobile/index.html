Como usar
  • Cada aparelho tem a largura real dele, então o site aparece com o layout de celular que o cliente vê.
  • Dividir tela abre até 3 janelas. Cada uma carrega um site; os aparelhos são os mesmos, para comparar versões lado a lado.
  • Toque, teclado do celular e Safari não são simulados: a conferência final é no celular de verdade.
  • Aparelho em branco: o site bloqueia ser aberto dentro de outra página. Use o botão de abrir em nova aba.
  • Diagnóstico automático e Rolar junto só funcionam com a ferramenta aberta pelo abrir.bat e o site em um endereço que começa com /. Veja o LEIAME.md.
